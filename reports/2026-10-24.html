🛠️ Vibe Coding 可玩的

给你的原型加一层「数据源降级」

今天就练这个：主接口失败时，自动切到备用源或缓存数据，页面上明确提示「数据可能不是最新」。实现思路很简单——try/catch 包住主请求，catch 里读本地缓存，读不到再展示占位卡片。十几行代码，但体验天壤之别。做完你会立刻明白为什么成熟产品很少白屏。

做一个「错误码翻译器」小工具

把你调用过的各平台错误码整理成一张对照表：码 → 含义 → 可重试吗 → 建议动作。纯静态页面就能做，用 JSON 配置 + 搜索框 实现。这是最容易做出来又真的会被自己反复用的原型类型，还能顺手练一下前端搜索过滤。

练「接口健康看板」的极简版

给自己常用的 3 个 API 写个定时探活脚本，结果存到一个表格里，页面上一张卡片一个绿/红点。定时任务 + 简单状态存储 + 一个列表页即可，不用上重型框架。注意：只探你自己的接口额度，别做高频请求。这个原型的价值在于让你对「系统可用性」有体感。
