「三个最常被问的问题」选题法

打开你的聊天记录或电话记录，找出客户最近问得最多的三个问题， 每个问题拍一条 30-60 秒的口播。开头直接说"每天都有人问我 XX"， 结尾给一个明确动作。这类内容的完播率和私信转化，通常高于追热点的泛流量视频。

「上周废弃素材复活」剪辑法

把过去 7-30 天拍废的素材全部拉到一个文件夹，按"画面清晰 + 有真人出镜" 筛出 5 条，重新写标题、配字幕、加一句老板观点。废素材的利用率往往能到 40% 以上，这是成本最低的更新方式。

🛠️ Vibe Coding 可玩的

给你的小原型加一层「失败兜底」

今天最直接的教训：任何一个调外部接口的原型，都该有 try / catch。 具体做三件事——请求加 超时设置、 把上次成功结果存本地 localStorage 当缓存、 失败时显示"数据暂时拿不到，这是上次的结果"。代码量极小，但体验差别巨大。

做一个「接口状态自查」小页面

写个单页应用，输入几个你常用的 API 地址，点一下批量测通， 用红绿灯显示状态。这对多接口拼起来的原型特别有用， 能让你在真正出问题前就知道哪个环节不靠谱。纯前端可实现，不需要后端。

用本地假数据先把界面跑通

API 挂掉的时候，最不该做的就是干等。给原型加一份 mock 数据，把界面和交互先跑顺， 等接口恢复再切回真实数据。这是独立开发者最该养成的习惯： 界面和数据的开发解耦。
